# Админка календаря — настройка для команды

Редакторы работают через **admin.html** — без Git, без кода, без Елены.

## Что сделать один раз (10 минут, делает Елена)

### 1. Google Таблица + скрипт

1. Создай таблицу: [sheets.new](https://sheets.new) → назови «Secret Room Calendar CMS»
2. **Расширения → Apps Script** → удали шаблонный код
3. Скопируй весь файл `google-apps-script-events.js` из репозитория
4. В коде смени `ADMIN_PASSWORD` на свой пароль (запомни — его дашь команде)
5. **Сохранить** → в выпадающем списке функций выбери `setupSheet` → **Выполнить** (разреши доступ)
6. В таблице появится меню **Calendar CMS → Импорт из JSON**
7. Открой `data/events.json` из репозитория, скопируй **весь файл** → вставь в диалог импорта

### 2. Опубликовать API

1. В Apps Script: **Развернуть → Новое развертывание**
2. Тип: **Веб-приложение**
3. Выполнять как: **Я** | Доступ: **Все**
4. Скопируй URL (заканчивается на `/exec`)

### 3. Прописать URL на сайте

В файле `data/cms-config.js`:

```js
window.CMS_CONFIG = {
  eventsApiUrl: 'https://script.google.com/macros/s/XXXX/exec'
};
```

Задеплой на GitHub (push в main) — сайт начнёт брать ивенты из таблицы.

### 4. Дать доступ команде

Отправь ребятам:
- Ссылку: `https://igaming-calendar.com/admin.html`
- Пароль (из шага 1)
- URL API (тот же, что в cms-config) — подставится автоматически после деплоя, но на всякий случай

## Как пользоваться (для редакторов)

1. Открыть **admin.html**
2. Ввести пароль → **Войти** (URL API уже может быть заполнен)
3. Слева список ивентов по месяцам
4. Кликнуть ивент → изменить поля → **Сохранить**
5. Через ~1 мин обновить сайт (Ctrl+F5) — изменения видны

### Добавить ивент

**+ Новый ивент** → заполнить название, месяц, даты, место → **Сохранить**

### Скрыть ивент (не удаляя)

Снять галочку **«Показывать на сайте»** → Сохранить

### Что ещё можно менять в ивенте

В форме ивента есть секции (листай вниз):
- **Погода** — температура и описание (пусто = блок скрыт)
- **Рестораны** — добавить/убрать, у каждого: название, вайб, чек, описание, фото
- **Бренды** — название, категория, логотип
- **Сайд-ивенты** — название, дата, место, описание, ссылка, тип, картинка

Кнопки «+ Добавить …» создают строку, «Убрать» — удаляет. Картинки в этих блоках грузятся так же, как обложка (кнопка выбора файла). Не забудь **«Сохранить»** после изменений.

**Картинки в блоках:** рестораны — горизонтальные (4:3 или 16:9); логотипы брендов — PNG/SVG на прозрачном фоне; сайд-ивенты — горизонтальные.

### Картинки

В форме ивента есть поле **«Загрузить свою картинку»** — выбери файл, он сам зальётся в Google Drive и подставится. После загрузки жми **«Сохранить»**.

**Требования к картинке:**
| Параметр | Значение |
|---|---|
| Ориентация | Горизонтальная (landscape) |
| Пропорции | 16:9 (как превью на YouTube) |
| Размер | 1600×900 px (минимум 1200×675) |
| Формат | JPG (фото) или PNG |
| Вес | до 400 КБ (лучше сжать) |
| Композиция | Главное — по центру, края обрезаются |

Можно также вписать путь/ссылку вручную в поле «Картинка» (например `images/heroes/x.jpg` или прямую https-ссылку).

## Пока API не настроен

- Сайт работает с локальным `data/events.json` (как сейчас в репо)
- Админка открывается **без пароля** в режиме только просмотра
- Редактирование заработает после шагов выше

## Безопасность

- Пароль хранится только в Google Apps Script и в браузере редактора (localStorage)
- Админка не ссылкуется с главной страницы — знают только по прямой ссылке
- Бот и авторизация Telegram **не используются**
