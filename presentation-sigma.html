06 — Promo code mechanics

This is not a public discount.

Controlled distribution — codes never leak to aggregators or search engines.

✕

What it is NOT

  • Not listed on coupon aggregators (RetailMeNot, Honey, etc.).
  • Not indexable by Google — code values never appear in plain text on the page.
  • Not a generic mass-market discount.

RU. Не публичный купон, не индексируется поисковиками, не утекает в агрегаторы.

✓

How it actually works

  • Unique codes — separate per ticket category (Standard / VIP / Afterparty).
  • Revealed only through a deliberate user click — "Get promo code" inside the SiGMA event card.
  • SiGMA's primary distribution stays through your own channels — calendar adds incremental CIS reach.
  • You can rotate or disable any code on your end at any time.

RU. Уникальные коды по категориям, раскрываются по клику внутри карточки. Основная раздача идёт через ваши каналы — мы добавляем СНГ-охват сверху.
